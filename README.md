# SteadyFrame

Checks video against published photosensitivity thresholds (WCAG 2.3.1, ITU-R BT.1702 /
Ofcom guidance), localises every hazard in time and space, and fixes it with the least
invasive change that its own analyzer then verifies. OpenCV 5, Python, AWS.

Entry for the OpenCV AI Competition 2026 (powered by AWS). Work in progress; see
`docs/PROGRESS.md`.

```
make install
make test
```

Not a medical device. See `docs/RESPONSIBLE_USE.md`.
